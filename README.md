# Галактика интересов

Интерактивная 3D‑визуализация в жанре Data Art: 230 участников Летней школы — это звёзды одной галактики.

Каждая звезда — один участник. По цвету, яркости и связям звёзд можно увидеть, какие направления интересуют участников, какой у них опыт и многие ли уже нашли команду.

## Исследовательский вопрос

Какое направление притягивает большинство участников и многие ли из них уже нашли свою команду‑созвездие?

## Как читать галактику

| Признак звезды | Что он означает |
|---|---|
| Цвет и скопление | Основное направление интереса участника |
| Размер, сияние и лучи | Уровень опыта: от маленькой тусклой точки у новичка до крупной звезды с лучами у продвинутого участника |
| Линии созвездий | У участника уже есть команда |
| Мерцание | Участник пока не знает, будет ли у него команда |
| Серебристые звёзды вне скоплений | Участник ещё не выбрал направление |

## Что видно

- **53%** участников (123 из 230) выбрали «Искусственный интеллект и анализ данных» — это синее ядро в центре галактики.
- **24%** (55 участников) ещё не выбрали направление и блуждают между скоплениями.
- **8%** (19 участников) уже в команде, остальные звёзды светят в одиночку.

## Возможности

- Галактику можно вращать мышью или пальцем, приближать и отдалять.
- При наведении на звезду или касании открывается карточка участника: направление, уровень опыта и статус команды.
- Кнопки направлений подсвечивают одно скопление, и камера подлетает к нему.

## Данные

Исходная таблица содержит 230 обезличенных участников и 8 столбцов. Для визуализации взяты три признака:

- основное направление (первое из выбранных);
- уровень опыта;
- статус команды.

Положение звёзд внутри скопления художественное. Состава команд в таблице нет, поэтому линии созвездий объединяют участников с командой внутри одного направления: они показывают, сколько таких участников, а не кто с кем в команде.

## Технологии

- HTML, CSS, JavaScript
- [Three.js](https://threejs.org/) (r128) — 3D‑сцена галактики и хромированная звезда в шапке
- Шрифты Unbounded, Manrope и JetBrains Mono из Google Fonts

## Запуск

Откройте `index.html` в браузере. Устанавливать ничего не нужно, но нужен интернет: 3D‑библиотека и шрифты загружаются из сети.

Чтобы опубликовать сайт через GitHub Pages, откройте в репозитории **Settings → Pages**, выберите ветку `main` и папку `/ (root)`.
